## 图片接入与失败回退

新增 `src/utils/midnightFoodImages.js`，映射以清单中的 `shopId:productId` 为键，避免按菜名猜图；资源版本来自清单的 `assetRevision`。映射只接入 Midnight 主题的运输车、菜单、购物区、详情、导航和商品推荐图。映射失败时保留商品原图，原图加载失败时使用 Midnight 的 `default-food.svg`。

浏览器中已确认 ID 27 的原图触发错误后切换到默认图，默认 SVG 加载成功（212×150），DOM 标记 `fallbackApplied=1`；当前菜品图无 `naturalWidth=0` 的失败项。所有生成图均以 `contain` 展示，没有对所有菜图做固定放大裁切。
