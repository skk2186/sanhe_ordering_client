# Phase04-R9R3：最高菜品与顶部进度条避让复核

## 状态

`READY_FOR_VISUAL_REVIEW`

本轮按审核基线 `dff03f6646d7e84ade881df5a5111bf89641807` 在 `themev2` 复测。真实页面的菜品可见边界与上一轮按源图透明边缘推算的坐标不同：3840 下页面已经有约 22px 的实际净空，1920 下约 73px。为避免把本来没有出现在屏幕上的透明边缘误当成可见内容，本轮没有移动进度条或改动其他布局。

## 复测方式与数据限制

- 使用本地 Vite 页面和单个无头 Chrome 会话，分别以 3840×1080、1920×1080 截图；截图及测量数据保存在被 Git 忽略的 `.visual-review/r9r3/`。
- 本地商品 API 服务 `127.0.0.1:48081` 未运行。浏览器仅对这两个菜单请求使用 R9 图片清单中的商品与分类数据，其余页面代码和静态图片使用仓库内容。价格使用截图测试值；图片仍由页面的真实 Midnight 商品映射加载。
- 为测量饮料真正绘制到屏幕上的边界，在页面中先截图，再仅隐藏 `food-18.webp` 图片并截图，对局部像素作差。这样能分辨图片元素框、透明像素与舞台裁切后的实际像素。

## 坐标和净空

| 视口 | 进度条容器 | 最高饮料实际可见顶边 | 实际净空 |
| --- | --- | ---: | ---: |
| 3840×1080 | y=52–176 | y≈198 | ≈22px |
| 1920×1080 | y=50–162 | y≈235 | ≈73px |

3840 下 `food-18.webp` 的图片框约为 x=1952、y=143.4、441.9×441.9px。其稀疏透明边缘经源图 alpha 推算可落到 y≈168，但 `.tide-stage` 从 y=196 开始裁切图片；逐像素对照确认饮料在页面上第一次产生可见差异的位置为 y≈198。进度设施图片的可见 alpha 下缘约 y=173.3，容器下缘为 y=176。因此，前次报告里的 y≈154 是源图边缘推算值，不是页面最终可见像素。

1920 下饮料图片框约为 y=217.1、365.4×365.4px，实际像素顶边约 y=235；进度设施图片的可见下缘约 y=159.6，容器下缘为 y=162。当前已有 73px 左右净空，没有改动 1920 定位。

## 移动空间与布局影响

- 3840 下 `.top-progress` CSS `top: 38px`，页面坐标 y=52，容器高 124px。进度挂架图片框顶部已到 y=-6；向上移动 20px 会把挂架顶部推到约 y=-26，新增约 20px 的裁切。只移动容器不能同时扩大净空并保住挂架完整度。
- 品牌牌匾实际范围为 x=28–468；3840 进度条为 x=1400–2440。助理气泡和角色分别约为 x=3196–3338、3346–3472，均未与进度条相交。1920 下品牌为 x=24–464、进度条为 x=560–1360、助理气泡为 x=1372–1496，也没有交叉。
- 3840 普通车轮图像框约为 y=571–696；特殊列车轮组约为 y=549–713。截图中轮缘与背景轨头在约 y=684–691 的区域接触。1920 普通车轮框约为 y=570–674。背景 v4 的铁轨是静态画面的一部分，本轮未触碰背景或车轮位置。
- 菜品、车辆、铭牌、文字、进度条尺寸均未变。3840 分类栏为 y=788、高 65px，底部点餐区从 y=867 开始、高 213px；1920 分类栏为 y=822、高 64px，点餐区从 y=900 开始、高 180px。两种视口都保持原尺寸。
