## 上一版问题与本轮结构

基线版本把菜名和价格放在同一条窄横牌中。3840 视口下名称/价格计算字号为 23/23.8px，1920 下为 19/19px；同一行争用宽度，名称长度稍长时尤其难读。

本轮将单行 copy 改为车厢侧面的两行铭牌：第一行菜名、第二行价格。铭牌使用深绿底、黄铜边框和上下阴影；两条黄铜支架从牌匾两侧延伸至车厢侧板，形成固定关系。牌匾位于车身中下段，宽度为车体的 44%、高度为 65%，整体矩形面积约为旧单行标签占车体面积的 1.5 倍。菜品图片区、车体图和车轮尺寸没有缩小。

牌匾占车体高度 30%–95%，底端仍在车厢轮廓内；车轮中心在牌匾两侧，只有轮组内侧边缘被牌匾遮住，浏览器边界框交叠约 25%，轮圈下半部仍可见且未碰轨道。菜名保持单行省略，完整名称仍在铭牌 `title` 和运输单元 `aria-label` 中。
