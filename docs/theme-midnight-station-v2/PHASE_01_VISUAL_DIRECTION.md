# 午夜月台 V2 · 视觉方向

## 1. 世界观定义

第三主题不是“带铁路元素的深色界面”，而是：

> 一座深夜仍亮着站灯、为顾客提供餐饮列车服务的真实月台。

用户进入页面时，应先感知完整候车空间，再理解商品是沿月台配送轨道经过。铁路辨识来自顶棚、立柱、架空线、站台边缘、枕木、道岔、远端线路、候车设施和站务设备的共同存在，不依赖月亮、图标或文字。

## 2. 最终母背景

- 主方案：`public/images/ui/midnight-station/background-v2.png`
- 尺寸：3840×1080
- 色彩模式：RGB
- 透明度：无；它是完整固定环境底图
- 图片文字：无
- 动态列车：无
- 动态信号亮态：无；信号灯壳保留，灯面未点亮
- 生成方式：OpenAI 内置图片生成工具；候选 B 经一次定向编辑后，机械中心裁切并高质量缩放到精确尺寸
- 候选 A：`background-v2-a.png`
- 候选 B / 最终来源：`background-v2-b.png`

### 主方案选择理由

候选 B 比 A 多出一条连续、低矮、结构明确的月台配送轨道，位置正好处于主舞台中下部；左右长椅、行李车、站务房和设备强化车站识别，中央区域仍有足够低对比留白。候选 A 更像从另一站台望向普通线路，配送逻辑不够明确，因此不作为主方案。

### 场景识别测试

本阶段进行了无标题视觉自检：隐藏“午夜月台”名称，仅查看 3840×1080 图和缩小预览。以下特征仍能共同指向“深夜铁路月台”：

1. 连续顶棚和重复的铆接铁柱；
2. 多组真实轨道、枕木、道岔和架空电力设施；
3. 月台边缘的触觉铺装与低位配送轨道；
4. 长椅、行李推车、站务房和电气柜；
5. 远端铁路灯、城镇与山体形成真实空间纵深；
6. 暖站灯与冷夜景的统一光照。

结论：通过。该结论是设计自检，不替代下一阶段的真实用户盲测。

## 3. 空间分层

### 远景

- 蓝黑夜空、低山和小城灯火；
- 多组远端铁路与道岔；
- 架空线、龙门架和远处站灯；
- 细节低对比，主要提供纵深和铁路规模。

### 中景

- 顶棚、铆接立柱、吊灯；
- 长椅、行李车、站务房、配电箱、栏杆；
- 主要铁路与月台边缘；
- 左右外侧信息丰富，中央相对安静。

### 主交互区

- 月台边缘前方的连续低位配送轨道；
- 下一阶段的菜品托盘车和特殊列车沿此轨道水平运动；
- 商品 DOM 位于轨道上方，轮组和底盘位于轨道附近；
- 同一条真实滚动流控制所有商品，不伪造多轨道数据层。

### 近景

- 湿润站台地面、接缝、污渍与灯光反射；
- 左右边缘有长椅、植物和设备形成局部遮挡；
- 底部较暗，承接左右购物车与中央功能台。

## 4. 透视与构图

- 视点：略高于月台面、近似正面观看；
- 主体透视：月台边缘和配送轨道接近水平，远端铁轨向中心偏右汇聚；
- 动态菜品只能沿水平配送轨道移动，不能随意上下漂浮；
- 标准菜品托盘应使用近正侧视，底盘下沿与背景低位轨道匹配；
- 特殊列车必须使用同一视点和暖冷混合光；
- 画面允许轻微非对称，避免控制室式绝对居中。

## 5. 光照

- 主环境光：冷蓝黑夜光，低饱和、低照度；
- 局部光：顶棚暖琥珀站灯，形成真实光池与湿地反射；
- 动态资产左、右移动时都必须保留相同受光方向；仅轮组/尾灯可做方向性变化；
- UI 外壳应以哑光漆、旧金属、木材和纸面为主，不使用大面积自发光边框；
- 信号灯亮态由独立 DOM/CSS 或小型透明素材实现，不烘焙进背景。

## 6. 材质语言

- 顶棚与立柱：旧涂层钢材、铆钉、轻微氧化和剥落；
- 轨道：油污钢面、局部锈色、真实固定件和枕木；
- 地面：混凝土/石材接缝、湿痕、磨损、细小颗粒；
- 候车设施：深色木纹、旧金属扶手；
- UI 实体：哑光深绿金属、暗木、米色票纸、少量黄铜；
- 禁止：镜面黑塑料、整面玻璃、过度圆润、统一发光描边。

## 7. 建议色板

颜色以背景实景为依据，下一阶段应转成语义 token，而不是在组件里散落硬编码值。

| 角色 | 建议值 | 用途 |
| --- | --- | --- |
| 夜空深色 | `#07111D` | 页面最深背景、遮罩 |
| 站棚黑蓝 | `#101B24` | 顶部、深色外壳 |
| 氧化深绿 | `#203833` | 控制台、车体主色 |
| 钢灰 | `#5D6662` | 边框、轨件、次级文本 |
| 湿石板 | `#333B42` | 底部设施、禁用态 |
| 暖灯琥珀 | `#D99B4A` | 重点、进度、信号 |
| 高光暖黄 | `#F2C978` | focus、短时反馈 |
| 票纸米色 | `#E5D7BC` | DOM 信息票、浅色表面 |
| 暗红 | `#8C3D34` | 删除、错误、列车尾灯 |
| 安全绿 | `#718E70` | 成功、通行信号 |

正常正文应至少达到 4.5:1 对比度；控制边界、focus 与图标至少达到 3:1。颜色不是状态的唯一表达，仍需文字或图形变化。

## 8. 3840×1080 UI 留白区

当前真实桌面布局在 3840×1080 下：顶部 196px，底部 213px，中间舞台约 671px。

| 区域 | 参考坐标 | 背景策略 |
| --- | --- | --- |
| 顶部信息区 | `y=0–196` | 暗顶棚/夜空，灯具只在外侧；不放高对比标牌 |
| 品牌区 | `x≈24–1000, y=14–184` | 左侧柱与暗背景提供层次，DOM 文字覆盖 |
| 投碟进度 | `x≈1449–2391, y≈8–110` | 中上部夜空低细节，不烘焙文字 |
| AI 助手 | `x≈2500–3812, y=14–184` | 右上方暗色环境；避免高亮对象正压角色 |
| 中央菜品运动 | `x=18–3822, y=196–805` | 配送轨道连续；中央 44% 低对比 |
| 分类/暂停 | `y≈805–867` | 深色地面/轨道下沿，保证按钮轮廓 |
| 左购物车 | `x≈668–1495, y=867–1080` | 暗湿地面，无文字或复杂物体 |
| 中央功能区 | `x≈1525–2315, y=867–1080` | 中央地面低频纹理，承接实体站务台 |

| 左/右菜单展开 | `y≈217–817`，从两侧展开 | 主背景中部保持低对比；菜单本身使用不透明实体面板 |

## 9. 组件视觉语言

### 菜品输送：小型餐饮托盘车

最终选择“低位铁路托盘车”，而不是普通盘子漂浮或完整小火车串联每一道菜。

- 每个商品有独立小型底盘、两组轮、低矮护栏和可更换餐盘；
- 商品图片与名称/价格仍为真实 DOM；
- 载具外壳是透明 WebP/PNG，轮动和接触阴影可分层；
- 底盘的轮距与背景配送轨道一致；
- AI 推荐可改变一盏小型琥珀指示灯和 DOM 徽章，不给整车加霓虹描边；
- hover/键盘焦点表现为站灯短暂照亮和轻微抬升，不改变轨距。

### 周期特殊节点：夜间餐饮特快

- 使用一台机车 + 一节特别餐车，整体建议宽 1100–1600px、高 300–420px；
- 占 4–6 个普通槽位，经过时一眼可见；
- 只在舞台配送廊道内通过，不遮挡顶部、底部购物车和分类按钮；
- 车灯、车窗暖光、少量蒸汽和轮下接触效果分层；
- 招牌菜触发器可位于餐车车门/展示窗，但文字和菜名由 DOM 渲染；
- reduced-motion 下取消蒸汽和轮动，保留低速平移或静态进入。

### 点餐进度：站台信号线路

- 复用 `TopPlateProgress` 的三层资产与 CSS 裁切逻辑；
- 底图是哑光站务线路板，填充是逐段亮起的琥珀线路灯，外框是旧金属压边；
- 百分比、标题、奖励说明全部 DOM/i18n；
- 进度满时从红/琥珀切到绿色通行状态，同时有形状变化，不能只靠颜色。

### 点餐台与购物车

- 中央功能区：实体站务/餐饮服务台，宽度继续匹配 790×217 业务占位；
- 左右购物车：候车座位旁的行李/餐票整理台，继续匹配 827×217；
- 四个购物车槽位像可插拔托盘位，不是四张玻璃卡片；
- 下单按钮像机械发车扳柄/确认牌，但仍是 DOM button，文字真实可翻译；
- 数量增减和删除保持清晰按钮与键盘操作，不做纯装饰机械机关。

### 菜单与招牌屏

- 侧边详细菜单：站务柜台翻开的纸质菜单夹或实体灯箱，使用不透明表面；
- 全局菜品导航：站内候车大厅/陈列墙，不依赖背景文字；
- 招牌菜：从顶棚结构降下的站内餐车展示屏，视频和文字均为 DOM；
- 主题设置卡片预览使用无文字背景缩略图。

## 10. 动效节奏

- 标准 hover/pressed：120–220ms；
- 托盘车接收/加购：420–620ms；
- 主题遮罩：900–1400ms；
- 特快列车完整经过：5–8s，周期不应短到持续打扰；
- 环境蒸汽/微尘：低频、低透明，8–18s；
- 禁止所有元素使用同一时长；禁止大面积闪烁和连续发光。

## 11. 最终生成提示词记录

使用内置图片生成工具，最终方案的核心提示词如下（为便于下一阶段复现，保留设计约束而非工具参数）：

```text
用途：3840×1080 桌面点餐界面的完整固定环境母背景，32:9 超宽。
场景：雨后深夜、略有年代感但维护良好的真实铁路月台。连续顶棚、旧铁柱、暖色吊灯、长椅、行李车、无字站务房、配电柜、架空线、枕木、道岔、多组远端铁轨、暗色小城与山体。月台边缘有一条连续、低矮、空置的窄轨配送轨道，供后续独立菜品载具运动。
风格：高质量动画电影手绘环境概念图，结构准确、材质自然、保留刷痕与磨损，不做光滑塑料 3D。
构图：中央 44% 与 y=30%–68% 保持相对安静；强识别设施放在外侧三分区；顶部 0–18% 暗且简单；底部 78–100% 为暗色低细节地面。轨道水平连续。
光照：冷蓝黑夜光 + 局部暖琥珀站灯；湿地反射；统一透视与光源。
硬约束：无任何文字、字母、伪文字、数字、站名、标志、Logo、二维码、水印、UI、HUD、菜单、食物、菜品、人物、列车、机车、车厢。标牌必须空白。信号灯壳保留但灯面不点亮。
禁止：赛博朋克、霓虹、玻璃拟态、发光边框、科技控制室、巨大月亮、塑料感、玩具感、扭曲铁轨、繁忙中央区。
```

定向编辑只关闭了红色信号灯亮态，并移除了相应红色反射；其余构图和材质保持不变。
