## R8 问题与 R8R 策略

R8 已经把普通车与菜图放大，但视觉注意力仍受车站背景细节影响。3840 下铭牌约 `211×104px`、1920 下约 `176×87px`；铭牌文字位于下半部，上方留白明显。R8 普通车的有效菜图绘制尺寸为约 `280×175px`（3840）和 `240×150px`（1920）。

R8R 再增加一档约 8%–10% 的车体/槽位尺度，菜图约增加 8%–11%，特殊列车同步轻微放大；不放大背景、不使用整舞台 `transform`，也不改横向滚动机制。

## 铭牌加宽与上下排版

- 铭牌相对车身宽度从 `44%` 调至 `48%`。结合车身一起放大后，绝对宽度在两个视口分别增加约 `19.8%` 和 `18.8%`，仍保留可见的车身侧板与轮组，不会铺满整车。
- 高度比例从 `65%` 收至 `56%`，顶部定位由 `30%` 调至 `38%`，铭牌底边仍挂在车厢侧板区域。
- 原来将菜名压在网格底部、价格靠近底缘的双行网格改为垂直 `flex` 居中：名称第一行、价格第二行、行间 `3px`、`1.02` 行高。铭牌分隔线移至两行之间，上下内边距平衡，减少上半部空白。
- 字号略增：3840 菜名/价格实测约 `31.9px/34.6px`（约32/35）；1920 为 `26px/27px`。菜名仍为单行省略，完整名称保留在 `title` 与按钮 `aria-label` 中。

## 整体舞台、轨道和特殊列车

- 普通车槽位从 R8 的 `500px/440px` 增至 R8R 的 `546px/480px`；槽间距在 1920 下从 `84px` 增至 `92px`，3840 下从 `118px` 增至约 `121px`。轨道基线继续由车厢高度计算，确保放大后轮组仍位于原照片轨道平面。
- 3840 全景约有 6–7 辆普通车进入画面，1920 全景约 4–5 辆；分别比 R8 少约一辆，边缘是否计入取决于循环槽位相交状态。实际截图没有相邻铭牌碰撞。
- 特殊列车从 R8 的约 `1760×360px` / `1375×340px` 增至 `1900×384px` / `1490×368px`（3840 / 1920），保持比普通车更高的视觉等级。事件时序与脚本不变。
- 背景素材保持原样。轨道为背景图绘制内容，未缩放背景；车辆槽位/间距与轨道基线配合调整，轮组持续接触既有轨道。
