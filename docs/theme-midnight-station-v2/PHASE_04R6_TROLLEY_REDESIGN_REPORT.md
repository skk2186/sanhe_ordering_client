# Phase04-R6：午夜月台一体式美食运输车重设计报告

**状态：`READY_FOR_VISUAL_REVIEW`**  
**审核基线：** `0ac2087812edf97e20d86871e4cf3ea7c5be8165`  
**分支：** `themev2`

## 旧版设计失败原因

R5R 在旧车体上继续放大圆形菜图和顶部横牌，菜图、车厢、文案仍是彼此分离的层。旧车体可用高度约 74–77px，轮组和底盘细薄；缺图时以深色背景托住空图片框，部分条目接近黑圆盘。3840 下的旧横向标签和菜图尺寸也没有形成匹配的车厢比例。

## 新运输单元与素材

结构现在是独立旋转轮组、透明车体、嵌入式椭圆托盘、按原图比例展示的菜品，以及车体正面的黄铜铭牌。食物底缘位于铭牌上方，托盘压在车厢台面内，车轮与既有轨道相接。普通车沿用舞台唯一的 `scrollLeft` 运动来源。

新车厢素材 `delivery-trolley-body-v3.webp` 为 2172×724、透明 RGBA WebP（257,846 字节）。主体按午夜月台的深绿、暖木、黄铜和深色底盘绘制；车体没有预绘食物、名称、价格或文字，轮组位置留给现有旋转轮素材装配。素材由图像生成器制作，并以原透明轮廓保留 alpha。另有独立 `delivery-trolley-platter.svg` 托盘（240×96）和 `default-food.svg` 默认食物图；页面切主题时会预加载这三项素材。

菜品图片使用 `object-fit: contain`，不再统一放大裁切。主图框在 3840 下为 165×98px，在 1920 下为 145×80px。铭牌为车体黄铜色，名称与价格同排显示，超长名称截断；完整名称保留在商品的可访问名称与详情数据中。

## 新旧比例

下表的 R5R 数值来自审核基线 CSS 推算；R6 数值来自浏览器 DOM 实测。

| 视口 | R5R 车体盒 / 高度 | R5R 菜图宽度 | R6 车体 | R6 托盘 | R6 主图 | R6 铭牌与字号 |
|---|---:|---:|---:|---:|---:|---:|
| 1920×1080 | 约 332×74px | 150px | 286×95px | 150×60px | 145×80px | 120×26px；名称 15px、价格 14px |
| 3840×1080 | 约 418×77px | 161px | 320×107px | 186×74px | 165×98px | 134×29px；名称 17.7px、价格 16px |

R6 车身比旧版更深、更厚，3840 下商品图略大，1920 下仍按可用槽位缩放。字号按铭牌实际面积设定，使常见菜名和价格能在同一铭牌完整显示；实拍检查确认可读。舞台槽宽为 1920 下 286px、3840 下 360px，间距保留共享几何。

## 图片缺失处理

没有图片时直接使用主题默认食物图。浏览器检查还将一辆可见商品车的图片临时指向不存在的本地图片地址，确认 `@error` 会切换到 `default-food.svg`；截图中占位图清晰可辨，没有黑色空圆。真实失败状态不会过滤商品。

## 业务回归与冻结范围

保留商品点击与 `dish-click` emit、左右方向、选中、推荐、售罄、暂停、键盘 Enter/Space 和可访问名称。车轮仍通过现有舞台滚动增量独立旋转；未更改共享横向滚动脚本。

`VirtualDiningAssistant`、`TopPlateProgress`、`MidnightExpressPass`、背景 v3/v4/v5/v6 资产以及 `zhenxian`、`xiaoxin` 均未修改。购物车状态与订单 API 未改。
