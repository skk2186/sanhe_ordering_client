## 下移空间与阻塞原因

3840 下，背景支撑结构下缘约 y=775–780，分类栏从 y=788 开始，当前仅约 8–13px 间隔。把完整轨道和支撑下移 40px 会将其下缘推到约 y=815–820，进入分类栏约 27–32px。即使缩到约 20px，支撑也会贴到或进入分类栏边缘；更小的位移不足以解除高饮料与进度条的重叠。

普通车当前在 1920 下的轮组底线比特殊列车约高 25–30px，说明仅给所有元素施加相同偏移也不能保证两种视口都落在同一条轨道上。需要先得到可用的背景重合成版本，再以统一屏幕轨道基线校正普通车和特殊列车。

本轮按图像编辑技能尝试以 v4 后景生成局部下移候选。生成结果画布为 2170×725，带上下留白，且夜景建筑和其他背景细节也发生改变；尺寸和像素保真均不符合要求，已拒绝，不复制到正式资源目录。当前工具没有提供可靠的精确遮罩式重绘能力，无法满足“只重做轨道、填补旧位置、其余背景锁定”的约束。

因此没有生成下移版全景、同视口对比或下移版 1920 截图，也没有修改 `--midnight-trolley-baseline`、`--midnight-rail-drop`、滚动逻辑或背景资源。可继续评审的仅为当前版本真实截图：

- `current-3840-drink-progress-clearance.png`：最高饮料与进度条间距。
