## 2. 原版显暗原因

检查基准为现存真实页面截图 `screenshots/phase04r2-A-original-v3-3840.png`（3840×1080）。按画面分区抽样统计，页面全图约 **68.2%** 像素亮度低于 40（8-bit 灰度）。夜空区（y=0–330）均值约 28.6，约 88.9% 像素低于 40；中央配送走廊（y=180–390）均值约 23.1，约 94.4% 低于 40；轨道/月台交界（y=300–430）均值约 23.5，约 92.4% 低于 40。

压暗主要来自：

- **背景中央配送区**：山体、树林和站台后方几乎连续为低亮度蓝黑，中央没有足够的暖光层次；两端灯柱亮，但中央的树、房屋和铁路电线仍聚成暗色轮廓。
- **轨道/月台**：钢轨与枕木被暗部吞并，地面只在几个灯下有细窄反光；湿地反射没有覆盖到中央活动区。
- **左右购物区**：深绿柜体、墨绿空盘位与深色边框连片；暖米色信息只出现在较小的商品/按钮块内。
- **中央功能区**：柜体和大多数搜索、记录、设置按钮都是深绿；两块米色菜单按钮彼此分离，造成深绿/浅色碎片交替。
- **分类栏**：工具条及普通分类全是深绿或蓝黑底；只有 active 分类偏黄，整体优先级仍被轨道和列车带走。
- **品牌与进度**：标题牌和金属灯格压在暗景上；0% 时灯格显棕暗，顶部文字对比也偏弱。
- **视觉抢眼程度**：全图只有约 5.5% 像素同时达到高饱和与高亮。车体、栏杆、灯架形成大面积高对比轮廓；食物数量虽可见，但明亮彩色区域分布小且部分数据项自身缺图/占位，第一眼的注意力仍容易落到铁路结构。

## 3. 暖夜背景 v4

已生成两张不覆盖 v3 的本地重调图：

- `public/images/ui/midnight-station/background-v4-warm-rear.png`
- `public/images/ui/midnight-station/background-v4-warm-foreground.png`

两张均为 3840×1080。处理基于固定像素位置的分区色彩重调：天空只做极轻调整，中央走廊抬升暗部细节，轨道边缘与湿地面获得更明显的暖黄/棕金反射。不是整图 brightness filter。

后景区域均值 RGB 变化：

| 区域（原图 y 坐标） | v3 | v4 warm |
| --- | --- | --- |
| 夜空（0–220） | 13.5 / 22.7 / 39.2 | 14.0 / 23.1 / 39.6 |
| 远景及配送带（220–400） | 15.8 / 24.4 / 38.8 | 18.9 / 27.0 / 40.8 |
| 轨道活动区（400–620） | 28.7 / 25.0 / 24.7 | 36.1 / 30.4 / 27.8 |
| 月台近景（620–820） | 60.1 / 43.4 / 32.6 | 79.5 / 56.6 / 39.2 |
| 湿地面（820–1080） | 59.6 / 47.0 / 40.8 | 80.2 / 61.6 / 48.5 |

几何检查：v4 与 v3 尺寸相同；前景 RGBA 的 alpha 通道逐像素相同，因此遮挡边缘和遮挡层逻辑保持不变。后景画布像素坐标不变，delivery corridor、轨道、柱子、月台和前后景轮廓未移动或重绘。原始 v3 资产仍保留。
