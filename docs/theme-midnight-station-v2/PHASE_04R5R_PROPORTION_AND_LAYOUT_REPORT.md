## R5 问题与本轮调整

- R5 将餐盘设为 200–232px，并把普通运输单元提高到 250–280px。代码构图中餐盘已经接近车槽宽度，远大于车体素材中部的金属承载区；餐盘遮住上层车身，普通车显得过重。
- R5 将商品名价格放在车体底部，并给信息条设置 56px 最小高度，覆盖了车身和轮组上方区域。
- 白边有叠加来源。主题样式明确设置了 `#fff7e5` 白色盘沿、`#f7eddb` 浅色底、4px 金色外圈和 24px 暖光；这些规则会形成外部亮环。现有浏览器画面中，移除 CSS 光环后商品照片边缘仍有白色/浅色像素，因此图片本身也包含浅色背景。照片由页面运行时数据提供，无法在本轮取得其原始文件做像素抽样。

### 运输单元尺寸与信息布局

- 餐盘：从 R5 的 200–232px 调整为 150–176px。按 CSS clamp 推算，3840 宽度约 161px、1920 宽度取下限 150px；这些是样式值推算，不是 `getBoundingClientRect()` 实测值。
- 普通车容器：从 250–280px 调整为 226–238px；车身图像高度使用 74–82px 的局部变量。特殊列车尺寸、轮组动画和运动代码未修改。
- 餐盘现在位于车体上方金属盘区域，沿用车辆中心线；商品名与价格改到餐盘上方的 36px 紧凑标牌，宽度不超过 300px，字号回到 20–22px，名称仍单行省略。底部车身正面不再放文本条。
- 删除 CSS 白色盘沿、宽金色外圈和暖光外扩阴影，改为 2px 暖灰金属边与克制的阴影。照片边缘以 1.16 倍轻微裁切减少图片自带浅色外沿，没有施加深色滤镜。
- 单张现有页面画面能同时看到普通车和特殊列车；目测普通餐盘没有盖过车头，车轮、车身下沿和轨道仍可辨认。该画面未保存为验收截图，未作尺寸标定。

### 底部购物区

- Midnight 购物车缩略图由 120–132px 调整为 88–100px（3840 样式值约 96px）；1920 断点使用 76–84px。
- 清除 Midnight 信息块 `margin-top:-22px`（1920 为 `-20px`）的叠放，改为正常纵向排列。基础槽高保持 184px，1920 断点保持 158px；四个商品槽仍使用同一规则。名称/价格区基础高度 40px、数量控制区 34px，1920 分别为 36px、30px。
- 购物区及中央面板原有共享高度规则未改。当前浏览器画面没有商品加购状态，无法确认四件、成功下单提示和数量控制的运行时呈现。

### 中央按钮与分类栏

- Midnight 中央菜单字号上限由 30px 降为 24px，功能按钮由 28px 降为 23px；1920 断点为 20px / 19px。
- 分类文字上限从 26px 降为 22px，按钮高度从 56px 调为 50px。样式限定在 Midnight 主题下。
