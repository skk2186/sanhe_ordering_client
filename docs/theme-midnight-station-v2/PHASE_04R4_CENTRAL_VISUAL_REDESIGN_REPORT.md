## 中央安全设计区分析

当前背景为 3840×1080，页面容器使用 `center/cover`：

- 3840×1080 视口展示完整背景，背景坐标为 x=0–3840。
- 1920×1080 视口按高度显示原尺寸背景，水平居中裁切 x=960–2880；这个横向交集是两种尺寸共同可见的区域。
- 实际 3840×1080 页面测得顶部栏 y=0–196、商品舞台 y=196–859、底部操作区 y=867–1080。商品滚动带在中央纵向区域覆盖背景，底部操作区会遮住更下方地面。
- 因此将主要设计放在 x=1680–2280、y=310–556：它位于 1920 的居中裁切范围内，也避开顶部栏、底部面板和 y≥560 的轨道区域。商品流会遮住新店铺下段，但营业窗上部在两种视口下均可见，形成背景在商品之后的空间关系。

## v5 为什么没有达到目标

R3 阶段的 v5 变化主要落在画面边缘，没有改变 1920 居中裁切下的中央建筑/营业氛围。中央商品流和操作区仍叠在原有冷暗月台上，窗口营业感没有形成清晰主体，所以本轮没有采用 v5。

## v6 中央改动与素材制作

使用内置图像生成编辑能力，以 v4 中央裁切作为参考，生成与原场景匹配的深夜车站寿司服务窗口：深森林绿木质立面、较宽的琥珀色营业窗、玻璃食品展示、寿司托盘和檐下灯。随后从编辑结果中提取店铺主体，以透明蒙版合成到 v4 后景的中央中景平台，并做柔边衔接。没有对整图套色、提亮或变换尺寸。

主要变化位于背景中央约 44%–59% 宽度，蒙版包围盒为 `(1680, 310)–(2280, 556)`。它新增的是可识别的营业设施、食物展示和局部灯光，不是边缘灯点或整体色温变化。夜空仍为深蓝，远山、村落和铁路夜景继续保留。

## 必答问题

1. **v6 中央区域改了什么？** 在背景中央加入深森林绿的站台餐饮窗口、寿司展示、檐灯和局部暖光。
2. **为什么 3840 和 1920 都能看到？** 店铺落在两尺寸共同可见的 x=960–2880 裁切带内，且营业窗上段处在商品流遮挡线以上。
3. **为什么不是边缘小修？** 蒙版主体位于中央 44%–59% 画幅，窗口横向约 600 像素，改变了中央中景的场景主体。
4. **为什么更有餐饮营业感？** 真实窗口结构、亮着的服务台、可辨识寿司托盘与成组照明共同表达持续营业。
5. **为什么更适合年轻用户？** 食物更醒目，灯光温暖且集中，整体保持夜间精致氛围，没有改成儿童风或夜店霓虹。
6. **是否保持夜间铁路辨识度？** 是。深蓝夜空、远山、立柱、完整轨道几何和前景遮挡关系保持；轨道区域像素核验一致。
