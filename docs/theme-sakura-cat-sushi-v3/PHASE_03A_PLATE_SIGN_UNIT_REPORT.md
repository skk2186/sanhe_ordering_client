# Theme V3 · Phase 03A 餐盘—牌匾单元报告

## 参考图与预览边界

已确认构图文件 `public/themev3-preview/confirmed-composition.png` 是用户提供的原图，实际尺寸 2048×768、RGB。预览按原比例显示在 3840×1080 逻辑画布中央（2880×1080），左右各留 480px；只作为静态设计参考，不作为正式背景。运动单元使用独立中性画布，避免与参考图中的静态猫咪、寿司及点餐台重复叠加。

## 运动单元

- 每个 button 根节点对应一个 mock 商品对象：`id/name/price/available/status/recommended`。餐盘调试形状、DOM 菜名、价格、推荐/售罄状态共用该根节点。
- 餐盘默认 340×210px，可调宽 300–380px；牌匾位于盘右侧，默认固定间距 24px，可调 16–64px。盘、牌匾与点击热区共享同一变换。
- 4 个单元沿 Phase 02R Catmull–Rom 弧线按弧长同步左→右运行。弧长约 4512px，单元间隔约 1128px；最大宽盘与最大牌匾间距下组合宽约 696px，仍保留约 432px 的弧长余量，不会相邻重叠。
- 保留暂停/恢复、调速、反向、复位、系统及手动 reduced-motion。点击或键盘 Enter/Space 均调用同一 button 激活路径，并发出 `dish-click` mock 事件；在售商品按点击左右显示 `handleSushiClick` 语义反馈，售罄商品显示提示。不连接真实购物车或下单接口。

Mock 样例包含长短中文名称、整数/小数价格、推荐及售罄状态；名称、价格与状态由 DOM 根据商品对象渲染，不写入任何图片。

**现场点击核验：未完成。** 自动化浏览器安全策略拒绝读取当前 `file://` 预览页面，因此没有伪称点击或键盘交互已经实测通过。代码保留了原生 button 键盘激活及事件反馈；需在本机预览中手动完成最终交互确认。
