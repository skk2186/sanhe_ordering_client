## 画面核对与限制

3840×1080 全景、1920×1080 中央视图、切菜板和炒锅的 100% 局部合成均已检查。砧板由木桌承托，摆盘猫和端菜猫的脚部不再显露于窗台，炒锅与灶台相接。底部三栏坐标为左 (668,865,827×217)、中 (1525,865,790×217)、右 (2345,865,827×217)；与回转带之间保有木质台面间隔。角色与插画台面仍有透视、颜色细节需要用户目视确认。

对照合成图保存在忽略目录 `.visual-review/themev3-phase03b2r/`：`cat-workstations-before-after.png`、`console-css-vs-illustration-review.png`，以及全景、中央和各接触点局部图。第二张上半部分是按旧 CSS 参数重建的对照图，**并非浏览器截图**。当前内置浏览器拒绝访问本地 `file://` 预览，因此没有宣称浏览器中的按钮点击与 100% 实际渲染已经验证；本地静态代码检查、PNG 数据核验和离线同坐标合成已完成。

`ART_ASSET_BLOCKED`：仓库仍没有经用户确认的 3840×1080 正式干净母背景。当前 2172×724 干净场景只在忽略目录 `.visual-review/themev3-phase03b2/background_clean_approved.png`，等比放到 3240×1080，左右各留 300px；柜台提取层只与此临时参考精确匹配。炒菜猫的锅、火焰、蒸汽和手臂仍烘焙在角色整图，独立蒸汽层及后续动作拆件未完成。正式 `/display` 接入与最终视觉验收仍待正式母背景和用户单独确认，本轮不进入猫咪动画。
