## 检查与限制

- 3840 全景、1920 中央视图及 100% 局部已用审批原图离线合成检查；检查图仅放在 `.visual-review/themev3-phase03b3/`，不提交。中央 1920 视图可见中央六按钮与左右下单区；两侧盘位需切回全景查看。
- 切菜板、摆盘/端菜猫腰线、炒锅底座和三组 UI 外廓在静态合成中可见；猫咪和 UI 原图细节较清晰。背景 2365×665 的细线条与木纹在 3840 目标下仍显软，临时插值不能恢复原生绘画细节；将来正式大屏应用仍需高分辨率背景绘制。
- 对本地 `file://` 预览的浏览器自动化访问被浏览器 URL 安全策略明确拒绝，故本轮**没有浏览器实测截图或实际点击结果**；DOM 热区按插画坐标与代码核对，浏览器视觉及键盘点击仍待可访问预览环境复核。
- `node --check public/themev3-preview/preview.js`、`git diff --check` 与 `npm run build` 通过。构建有仓库原有 Sass 弃用和大包提示，不影响完成；首次受执行环境 `realpath(index.html)` 权限错误影响，重跑后成功。

预览入口：`public/themev3-preview/index.html`。默认打开新版完整静态合成，可切换确认构图、新背景、猫咪工位、独立点餐台和 Phase 03A 运动调试；可切换原始/临时增强背景及调试线框。
