## 3. 合成图层与餐台几何

完整场景层序：

1. 3840×1080 母背景
2. 后厨角色预留层（当前无猫咪图像；仅有默认关闭的调试标记）
3. 餐台后沿
4. 回转带面
5. 动态餐盘（本阶段只用可关闭的调试盘验证）
6. 餐台前缘遮挡层
7. 底部点餐台与左右购物盘预留区

后沿、带面与前缘来自同一整台母稿，透视与宽度一致。结构按各自轮廓遮罩，带面与前缘共享接触边；三层图统一竖向缩至 84% 并围绕画布中心定位，保留餐台横向全宽并为底部留出空间。动态层位于带面上方、前缘下方，使前缘可遮住盘底。

预览运动中心线按后沿下边界和带面前边界的中线取样，再套用相同的竖向缩放；Catmull–Rom 曲线通过这些采样点，左→右为默认方向，端点位于画外。默认测试盘保留 340×210 逻辑像素。轨迹是基于这版餐台几何的首轮拟合，不代表最终商品盘的透视、深度缩放和遮挡模板已通过美术验收；应在正式商品盘完成后再微调。

## 4. 合成预览与视口检查

- **3840×1080 全景：** 已在完整合成视图检查背景、餐台分层、横向延展和底部留白。母背景两侧本身有货架、灯笼与厨房陈设，没有以纯色条或模糊拉伸补边。按当前餐台 84% 竖向缩放，中心前缘最低处约 y=842，底部业务布局从 y≈865 开始，约留 23 px 缝隙；没有直接覆盖业务区，但余量较窄，正式点餐台外框须据实际插画再次测量。
- **1920×1080 中央视图：** 预览提供固定逻辑画布中心裁窗（母版 x=960–2880），已检查中央窗景、餐台弧线和中央底部区域。该模式是场景裁窗，不等同于生产页面在 1920 CSS viewport 下的响应式布局。Phase 02R 记录的生产 `/display` 两侧各约 276 px 溢出、每侧仅 2/4 个购物槽完整可见的问题仍未修复；本阶段未改业务界面。
- **100% 局部：** 可切换到逻辑像素 1:1 查看并拖动画布；支持快捷聚焦餐盘、弧线和点餐台。
- **层级检查：** 可单独查看母背景、餐台母稿、后沿、带面、前缘；可隐藏前缘测试遮挡；可在正式背景与 2048×768 参考图之间切换。
- **调试分离：** 正式背景/母稿不含调试盘、控制点、框线、参考线或模拟文字。调试覆盖默认关闭，显式开启后才显示角色工位标签、轨迹与测试盘；底部布局对照也是独立调试开关。

预览入口：`public/themev3-preview/index.html`。逻辑场景尺寸固定 3840×1080，视图缩放和裁窗不改变其坐标。

## 5. 尚未完成与下一阶段

- 母背景仍需人工美术把关，特别是降低木材高光、纹理细节和整体明暗反差，使其更贴近用户原 demo 的扁平柔和风格。
- 传送带运动目前是 DOM 测试盘沿拟合中心线移动，不是带面纹理平移；没有商品盘模板。需在最终商品盘进入后检查盘底前缘遮挡、接触阴影、转弯透视、两侧进出场及后台动画周期。
- 餐台中心前缘与业务区仅约 23 px 几何间隔，正式点餐台素材加入后要复核重叠；1920 下生产购物盘响应问题仍由后续业务布局工作处理。
- 本阶段没有正式角色文件。下一阶段需制作四只独立透明猫咪资产：切菜猫（身体/前臂/爪/刀具分层）；摆盘猫（身体/手臂/爪/商品或寿司/盘子分层）；端菜猫（身体/双手/托盘组合，支持右侧入场）；炒菜猫（身体/手臂/锅铲转轴/锅沿/火苗或蒸汽分层）。需提供统一视角、锚点、站姿，以及对应循环动作帧/独立可动件和 alpha 清理边缘。
- 本阶段没有制作正式点餐台、购物盘壳、商品图、进度条或 AI 助手图。

## 6. 验收结论

**有条件通过视觉资产首批交付。** 3840×1080 母背景、独立餐台母稿和三张透明餐台层已实际生成并接入预览；动画与响应式部分保持待后续校准。正式角色、商品盘、独立点餐台以及生产 1920 响应布局尚未完成，不能视作完整主题验收。

提交前执行 `git diff --check` 与 `npm run build`。预览素材尺寸及透明通道按本报告上表核验；构建结果、提交 SHA 与推送状态以交付消息为准。
