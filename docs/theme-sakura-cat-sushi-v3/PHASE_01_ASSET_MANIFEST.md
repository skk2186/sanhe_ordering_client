# Theme V3 Phase 01：资产清单与目录规划

资源根目录：`public/images/ui/sakura-cat-sushi/`。目录已创建并含 `.gitkeep`；本阶段不加入图像、不修改现有 b/c 资产、不将新主题注册进运行时。

## 目录结构

```text
public/images/ui/sakura-cat-sushi/
├── background/   # 3840×1080 母背景及经过验收的背景变体
├── stage/        # 弧形回转餐台、护板、轨道前后景、接触阴影
├── cats/         # 角色原稿、拆件、精灵图与循环动作
├── plates/       # 可点击餐盘基底/状态和商品实图的遮罩辅助
├── console/      # 中央点餐台/服务台主体
├── effects/      # 蒸汽、花瓣、灯光、火苗等透明效果
├── progress/     # 进度条底图/填充/外框
├── cart/         # 购物车、盘位、提示、下单外壳
└── transition/   # 主题切换专属转场资产
```

## 导出与验收约定

- 资产制作时同时保存可编辑源稿到项目约定的源文件存储位置；运行时只引用压缩后的 PNG/WebP/精灵图，不把生成过程稿混入该资源目录。
- 透明资产需要检查 alpha 边缘、基线、中心锚点和实际缩放；避免有白底/白边的素材叠在木色背景上。
- 每组动作提供合成静态回退图；动画层记录帧率、帧序、锚点和循环长度。资产文件名采用小写 kebab-case，避免临时 v-final-final 命名。
- 每次资产集成需在母版尺寸 3840×1080 与产品实际常用的 1920×1080 下复核主体占比、文字空区、碰撞、点击热区与层序；输出验收截图和真实尺寸记录。
- 本清单是生产规划，不代表上表资产已制作或浏览器效果已验证。
