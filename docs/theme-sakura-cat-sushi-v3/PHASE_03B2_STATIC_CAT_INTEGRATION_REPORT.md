## 静态场景合成

预览逻辑画布保持 **3840×1080**。临时干净场景为 **2172×724、3:1**；按原比例缩放至 **3240×1080**，居中显示，左右各留 300px，不横向拉伸、不模糊补边。背景仅从本地忽略目录 `.visual-review/themev3-phase03b2/background_clean_approved.png` 读取，故 Git 提交不含该参考图。

默认角色均为 0.23 倍，约 **258×322px**；x/y 是脚底接触锚点，默认 y=495。x 可调 300–3540、y 可调 120–820、缩放 0.15–0.38、层级 18–40；每只角色均可独立隐藏。默认位置：切菜猫 (900,495,z22)、摆盘猫 (1300,495,z23)、端菜猫 (2700,495,z23)、炒菜猫 (3150,495,z24)。

图层从后到前为干净场景临时参考、静态猫咪、可选底部业务结构对照和调试标记。全景、1920×1080 中央视图和 100% 局部均已检查；四猫落在对应后厨工位，主体仍是店内与中央窗景，角色下缘与回转带面保持间隔。

背景是单张 RGB 合成图，台面前沿没有独立遮挡蒙版。因此当前只能调整角色位置和互相层级，不能让台面前沿真实遮住猫咪下缘；现有接触关系是静态预览估位，不能作为最终深度合成验收。
