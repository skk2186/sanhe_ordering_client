# Theme V3 Phase 02：3840×1080 构图与动态传送原型报告

日期：2026-10-26
分支：`themev3`
性质：独立开发预览，不挂入正式主题、不接触订单或商品数据。

## 1. 参考图实测与适配判断

用户提供的 `sakura_cat_themev3_reference_demo.png` 实测为 **2048×768 px、8:3（2.6667:1）**；目标画布为 **3840×1080 px、32:9（3.5556:1）**。两者比例明显不同。

按高度等比放置时，参考图为 2880×1080 px，逻辑画布左右各需新增 480 px。原型采用这一换算：不横向拉伸、不裁掉人物；新增区域以斜纹“待重绘扩展”标识。按画布宽度铺满会得到 1440 px 高并超出目标高度，居中裁切会损失上下内容，因此没有采用。

参考图中的内容与限制：

- 四只猫、两侧货架和蒸笼、多盏吊灯、中央窗外樱花小镇、弧形餐台、约八张静态餐盘和右侧前景碗碟都已烘焙在同一张图中。
- 图片没有点餐台；上部灯笼、布帘和猫耳等主体较拥挤，不能直接视作最终顶部控件背景。
- 原图餐盘是静态像素，不可作为运动对象。正式母背景绘制时需移除所有固定餐盘，再以独立可点击餐盘资产覆盖。
- 这张图只在独立预览中作比例/位置参照，文件被 Git 忽略，不会随阶段代码提交。

## 2. 3840×1080 构图规则

预览页面以 `data-canvas-width=3840`、`data-canvas-height=1080` 固定逻辑坐标。浏览器只对整个场景作等比缩放以适配页面空间，坐标与比例不随窗口改变。全景查看完整母版；中央视图是逻辑 x=960–2880 的 1920×1080 居中裁窗，不缩放或拉伸场景内容。实际 DOM 核验得到全景 3840×1080、中央裁窗 1920×1080，场景左偏移 -960 px。

构图分区（均为逻辑画布坐标，边界是调试覆盖层）：

| 区域 | 预留范围 / 参考 |
| --- | --- |
| 顶部信息安全带 | y=0–196；品牌左上、进度条居中（现有进度条最大宽约 941 px）、AI 助手右上 |
| 猫咪工位 | 参考图上层中段；角色需从背景独立拆出，避免侵入顶部信息带 |
| 回转餐台与餐盘交互区 | y≈196–863；运动盘热区沿餐台带面布置，需保留明确前后景层 |
| 左购物盘 | x=668、y=863、827×217 |
| 右购物盘 | x=2345、y=863、827×217 |
| 中央点餐台 | x=1450、y=820、约 940×260；底部伸至画布边缘 |
| 点餐台按钮安全区 | y=863–1059；菜单、导航、历史、设置、呼叫店员五个按钮，各约 136×196 |

点餐台目标范围与左右购物盘在画布下段水平并列，需用独立插画资产制作；边界框仅用于占位验证。正式位置需在餐台前缘与菜品点击区的实图资产完成后复核，确保点餐台不覆盖餐盘热区。左右购物盘继续使用既有组件及业务规则。

## 3. 猫咪工位与资产层级

下表先以原图像素框作估测参考。等比适配系数为 1.40625，目标画布 x 还需加左扩展偏移 480 px；这些框只是站位参考，并非最终抠图边界。

| 工位 | 原图参考框 | 动作与拆件 | 层级、锚点与循环建议 |
| --- | --- | --- | --- |
| 切菜猫 | x=300–520、y=150–350；目标约 x=902–1211、y=211–492 | 刀具、持刀前爪、食材板独立；固定上臂/肘/腕锚点 | 身体在后、前爪和刀在台面前；刀尖沿短弧下切再抬起，首尾都回到刀尖离开砧板的静止姿势。不可整体上下移动角色。 |
| 摆盘猫 | x=520–790、y=135–355；目标约 x=1211–1591、y=190–499 | 双手、正在摆放的寿司、工作盘分层 | 身体后、手与工作盘在前；手腕绕盘缘短幅移动，循环末盘与手回到起始相对位。 |
| 端菜猫 | x=1370–1610、y=135–355；目标约 x=2408–2744、y=190–499 | 托盘、双手、菜品组成可整体持握组 | 手/托盘在身体前；肩和腕锚点协同短距离送盘，终点对准传送带入口；首尾保持托盘水平。 |
| 炒菜猫 | x=1610–1880、y=130–360；目标约 x=2744–3124、y=183–506 | 锅、锅沿前片、锅铲、火苗、蒸汽分别拆层 | 身体与锅后片在后，锅沿和手在前；锅铲绕腕/锅沿轴转动，火焰与蒸汽单独循环；炒锅动作回到锅内起始角，不移动整只猫。 |

最终角色应由透明插画资产或成套可动画部件绘制，支持前后遮挡和锚点复用；当前预览没有生成或伪造猫咪素材。

## 4. 传送动线与原型验证

路径以参考图中盘面接触线作近似拟合，使用 10 个 Catmull–Rom 控制点与采样后的弧长表插值，点间按弧长等距布置。端点延伸到画布外，确保盘子离开可视边界后才从另一侧进入；不会在中央跳回。坐标（px）：

`P1(-240,557) → P2(480,548) → P3(900,545) → P4(1320,556) → P5(1740,570) → P6(2160,571) → P7(2580,558) → P8(3000,543) → P9(3360,534) → P10(4080,515)`

这些点来自参考图中餐盘中心线按 1.40625 倍缩放并加 480 px 左扩展的初始人工拟合，后续应在干净的分层餐台图上重新标定。每只调试盘按所在路径位置微调高度、切线角度、层级和缩放，以模拟沿弧形带面行进；默认 8 盘按全路径等弧长间隔，默认速度 220 px/s，可调 80–360 px/s。

已实现的独立原型行为：

- 左→右连续运行、暂停/继续、方向切换、速度滑杆和回到起点。
- 8 个 DOM 测试热区随路径移动，点击后显示对应编号，不访问菜单、购物车或订单数据。
- 手动模拟减少动态模式与系统 `prefers-reduced-motion` 均停止自动位移，保持静态分布。
- 可显示/隐藏控制点、路径、站位及安全区等调试标记。
- DOM 实测 10 个控制点与 8 个热区。220 px/s 下 1 秒样本的首盘沿轨迹前进约 230 px（采样时间略受帧边界影响）；暂停期间样本不变；360 px/s 反向运行约 1.5 秒后首盘 x 减少约 555 px；运行中的减少动态模式样本保持不变。轨迹首尾延伸画布外，周期交接仅发生在画面外。
- 调试圆盘为简化标记，不是餐盘素材；参考图中的静态盘仍可见，是因为它属于被测底图。正式背景必须去除它们，避免与真实动态盘叠加。

## 5. 正式资产边界

- **静态母背景可保留：** 建筑结构、固定货架/墙面、窗外小镇与樱花、固定灯笼外壳、地面和不参与动画的环境装饰。灯笼光晕/火苗若需闪动，应拆成效果层。
- **必须独立绘制：** 四只猫及动作部件；回转餐台后沿/带面/前缘等前后景；所有可点击餐盘及盘底；中央点餐台主体及按钮壳。
- **由真实 DOM 承载：** 菜名、价格、进度百分比、购物车内容、导航文字、设置与呼叫状态。沿用现有菜单和购物车数据及事件链。
- **需独立循环素材：** 切菜手臂/刀具、摆盘手/寿司、端菜手/托盘、炒锅/锅铲、蒸汽、火苗、樱花瓣、必要的灯笼光效。
- **需要沿用的业务边界：** 既有展示页菜单商品流、左右购物车、中央功能面板、进度条、设置弹窗、特殊事件触发与转场的接口/状态机制。Phase 02 未接入这些业务组件，未修改正式展示代码。
- 尚未具备可用的干净母背景、拆层角色、传送台、点餐台、盘子、购物车/中控外壳及转场图；它们是进入正式视觉集成前的美术依赖。不可用 CSS 拼贴替代。

## 7. 下一阶段建议顺序

1. 锁定 3840×1080 正式构图线稿：重画左右各 480 px 扩展，并让顶部信息带、四猫工位、带面、购物盘与点餐台互不冲突。
2. 生产无人物、无固定餐盘的分层母背景；先确认餐台前后景和中央点餐台占位。
3. 制作四只猫的静态全身资产与可拆动作部件，按动作锚点和遮挡关系出图，再做循环姿势。
4. 独立制作正式餐台、DOM 餐盘底图、点餐台、购物盘和中控/按钮外壳。
5. 用正式餐台图重新取至少五个路径控制点，校准盘子前后层级、点击热区和越界再入。
6. 制作蒸汽、火苗、花瓣及转场/进度素材；按资源清单完成命名与尺寸规范。
7. 在隔离的主题适配层中接入现有展示组件与业务事件，保持商品和购物车数据逻辑不变，再做正式界面的构建与交互回归。
