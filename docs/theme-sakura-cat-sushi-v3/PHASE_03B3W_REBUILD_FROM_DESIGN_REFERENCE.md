| 摆盘 | **局部重建。** 新透明图 `cats/cat02-plate-design-w.png`（1415×1112）按设计稿恢复双手端单贯寿司和连续腰身；显示锚点 `(1230,600)`、缩放 `0.29`。沿用已收窄的 `plate-worktop-narrow.png`，真实台口从 `y=565` 遮下身，餐盘完整高于台口，左侧食材与袖口分离。 |

四张新工位图均为带实际 alpha 的 PNG；后台修补图是局部不透明插画，CSS 蒙版仅用于边缘过渡。旧猫、旧台口与旧锅火保留于“上轮工位对照”模式，不参与新版合成。预览可在上轮/新版间切换，再用四个局部按钮逐只比较。

已在 `.visual-review/themev3-phase03b3w/` 生成未入库的修复前后 3840 全景、1920 中央视图和四个工位 100% 局部图。离线合成检查显示：新砧板与桌边平行，摆盘和端菜腰身接触台口，炒锅火焰落入嵌入灶位，未见前轮的悬空、切片或摆件穿插。浏览器工具因 `file://` 安全策略拒绝读取本地预览，故**浏览器实际显示与用户视觉验收仍未完成**。背景仍是临时插值放大图；若进入动作制作，需先拆分四个新静态工位中的手臂与道具。
