# Theme V3 · Phase 03R Stage Redo Report

## 结论

Phase 03 的高墙式回转台已由一套重新绘制的低矮弧形餐台替换。新合成将店内、中央樱花窗景和后厨重新放回视觉主体；旧稿的大面积挡板与夸张端部不再出现在正式资源或预览中。

本轮已完成母背景、餐台透明分层、合成预览和运动轨迹的空间重校。3840×1080 全景与 1920×1080 中央视图均已复核。`ART_ASSET_BLOCKED`：否。当前素材可进入主题开发；最终餐盘接触表现需待正式餐盘模板阶段再校验。

## 1. 旧方案问题与重做原因

Phase 03 的整套餐台视觉形成过高的弧形前墙，带面宽、前缘厚，左右端上翘明显。它盖住后厨柜台和窗景下部，把原本的寿司店内景压成一条被台体切开的背景。旧资源 CSS 又额外做了 `scaleY(.84)`，令实际几何与运动路径难以保持共同透视。

这些问题来自整套台体的纵深和端部轮廓，而非单一坐标偏差，因此本轮废弃旧结构并重画母背景和餐台。旧失败图片没有复制到正式预览目录；旧版本仍可在 Git 历史中追溯。原始 demo 保留为独立参考切换项。用户提到的失败截图在本地文件与本轮消息附件中均未找到，复核依据是失败描述和仓库内 Phase 03 原资源。

## 2. 新母背景设计

新背景重建为 32:9 室内全景：顶部留有品牌与状态信息安全区，中央窗景展示樱花小镇、远山和塔楼，两侧保留货架、餐具、蒸笼、灯笼与室内结构，后方为连续操作台，下部保留木地板。画面不含固定寿司盘、猫咪、回转台、点餐按钮或文字 UI。

生成源图为 2172×724；从底部裁去空余区域后按单一等比缩放，输出 3840×1080，没有拉伸 2048×768 demo。当前插画有清晰的暖色轮廓与柔和室内感，但仍带有较强的细节、高光和渐层，尚未完全达到目标中的低对比纯平涂；这属于下一轮美术风格统一项，不影响空间结构校验。

## 3. 新餐台几何与透视

餐台重画为内置于中下部的浅弧形设施，后沿、连续带面和前挡板共享同一条缓和曲线。前后弧线平行，左右端向画面边缘浅收，端部未做高翘坡道或半管造型。活动带面为空，不含固定商品、餐盘或商品名称。

- 逻辑画布：3840×1080。
- 中部带面可见深度：约 150px。
- 中部前挡板可见高度：约 115px。
- 中部后沿至前挡板底部总高度：约 305px。
- 运动中心线：中心约 y=624px，两侧约 y=573px，沿统一浅弧平滑过渡。
- 合成后餐台最下缘约 y=815px；底部 UI 预留从 y=865px 开始，留有约 50px 间隙。

动态餐盘置于带面之后、前缘之前；前缘可遮住餐盘底部。路径保留左→右默认运动和 340px 默认盘宽，没有修改业务数据或接口。运动曲线是基于新带面的空间校准，最终接触阴影与真实商品盘仍待正式餐盘模板确定。

## 6. 新旧效果与验收检查

**遮挡：明显改善。** 旧稿的高挡板和厚重端部已消除；新稿让店内结构、樱花窗景和后厨储物再次可见。中央视图中餐台仍是明确的中景交互主体，会遮住窗下沿和后厨柜体的下部，但不再盖住大部分窗景或把全场切成两段。

**透视：已统一到合理浅弧。** 后沿、带面、前缘与运动中心线使用相同轮廓，桌面深度和前缘厚度受控。当前浅弧的左右两端仍比中心略高，这是远端回转路径进入侧边的透视表现；没有继续向上卷成墙体或滑道。正式餐盘与猫咪层加入后仍需做接触和遮挡复查。

**3840 全景：通过。** 母版保持 3840×1080；顶部信息安全带清晰，中央窗景保持为重要锚点，左右店内空间完整可辨，餐台与 y=865px 起的底部预留区未重叠。

**1920 中央视图：通过。** 以画布中央 x=960–2880 的 1920×1080 视图检查，窗景主体仍连续可见；餐台处在中下部，和底部 UI 预留之间有呼吸间隔。

`public/themev3-preview/index.html` 提供正式背景/原始参考切换、背景单独查看、餐台母稿与三结构层单独查看、前缘显隐、3840 全景、1920 中央视图、100% 局部检查、运动方向/速度/暂停控制，以及可显隐的边界标记、猫咪工位、运动路径与调试盘。底部调试覆盖延续 02R 三栏布局：左四槽与右侧下单、中间双菜单加 2×2 功能区、右侧下单与四槽。

## 8. 尚未解决与下一阶段

- 新图比 Phase 03 旧版更适合当前布局，但背景与餐台仍比目标纯平涂风格更细致、更有高光；后续美术统一可降低细节密度与局部对比。
- 四只猫咪角色和正式餐盘模板尚未制作。站位目前仅有可选的调试标记，未烘焙占位角色。
- 猫咪与正式餐盘加入后，需要复核脚部/盘底接触、前缘遮挡和端部进出场。
- 底部点餐台仍是空间预留和调试结构，不是正式插画资产。

下一阶段可以开始猫咪角色资源制作，并以本轮母背景和浅弧餐台作为空间锚点；完成角色合成后应再校准站位和遮挡。
