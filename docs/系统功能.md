# 回转寿司点餐系统前端功能文档

## 系统概述

本系统是一个基于Vue 3的回转寿司点餐系统，采用现代化的前端技术栈，提供沉浸式的点餐体验。系统包含传送带大屏显示、菜单浏览、桌台绑定、管理后台等完整功能模块。

## 核心功能模块

### 1. 传送带大屏显示系统 (`/display`)

#### 1.1 传送带核心功能
- **无缝循环滚动**：实现真实传送带效果，支持无限循环浏览
- **智能拖拽交互**：支持鼠标和触摸拖拽，包含动量滚动和惯性效果
- **响应式设计**：适配多种屏幕尺寸，优化大屏显示效果
- **性能优化**：采用虚拟滚动技术，确保大量菜品流畅显示

#### 1.2 投碟进度系统
- **进度追踪**：实时显示用户投碟进度(0-5个)
- **游戏化体验**：满5个投碟获得扭蛋机会，增加互动乐趣
- **视觉反馈**：动态进度条和数字显示，直观展示进度状态

#### 1.3 智能购物车系统
- **双侧购物车**：左右两个独立购物车，根据点击位置智能分配
- **实时更新**：商品数量实时调整，支持增减和删除操作
- **订单管理**：完整的下单和结账流程

#### 1.4 寿司盘交互
- **点击选择**：点击寿司盘自动添加到对应购物车
- **拖拽操作**：支持拖拽寿司盘到购物车
- **视觉效果**：丰富的动画效果和状态反馈

### 2. 菜单浏览系统 (`/menu`)

#### 2.1 分类导航
- **CategoryNavigation组件**：顶部分类导航，支持快速切换
- **图标展示**：每个分类配有专属图标，提升视觉识别度
- **滚动导航**：支持横向滚动浏览所有分类

#### 2.2 菜品展示
- **MenuItemGrid组件**：网格式菜品布局，清晰展示菜品信息
- **DishCard组件**：精美的菜品卡片，包含图片、名称、价格等信息
- **状态标识**：新品标识、售罄状态、推荐标签等

#### 2.3 搜索功能
- **SearchBar组件**：强大的搜索功能，支持菜品名称和分类搜索
- **实时搜索**：输入即搜索，快速定位目标菜品
- **搜索历史**：保存搜索记录，提升用户体验

#### 2.4 特色功能
- **FeaturedCarousel组件**：首页轮播推荐，展示特色菜品
- **FilterTags组件**：标签筛选功能，按口味、价格等条件筛选
- **MobileBottomNav组件**：移动端底部导航，优化移动体验

#### 2.5 寿司导航
- **无界大菜单**：点击寿司导航按钮后打开全屏的无边界菜单界面
- **自由拖拽浏览**：用户可以在任意方向自由拖动菜单，实现无限制的浏览体验
- **分类整齐排列**：所有菜品按照类别进行分组排序，每个类别区域清晰标识
- **平铺式布局**：菜品以网格形式整整齐齐地平铺展开，便于快速浏览和选择
- **类别标题显示**：每个分类区域配有醒目的类别标题，通常采用红底白字的设计风格
- **直接加购功能**：点击任意菜品可直接添加到主页面的购物车中
- **响应式交互**：支持触摸和鼠标操作，提供流畅的拖拽反馈
- **视觉层次**：通过颜色、间距和布局营造清晰的视觉层次，提升用户体验

### 3. 用户认证系统

#### 3.1 多角色登录
- **顾客登录** (`/customer-login`)：顾客身份验证
- **员工登录** (`/login`)：员工和管理员登录
- **权限控制**：基于角色的访问控制，确保系统安全

#### 3.2 桌台绑定
- **TableBinding组件**：顾客扫码绑定桌台功能
- **会话管理**：维护用户会话状态和桌台信息

### 4. 管理后台系统 (`/admin`)

#### 4.1 仪表盘
- **Dashboard**：系统概览，展示关键业务指标
- **数据可视化**：图表展示销售数据和运营状况

#### 4.2 菜品管理
- **Categories管理**：菜品分类的增删改查
- **MenuItems管理**：菜品信息的完整管理
- **图片上传**：支持菜品图片上传和管理

#### 4.3 用户管理
- **Users管理**：用户账户管理和权限分配
- **角色控制**：灵活的角色权限体系

### 5. 演示和测试模块 (`/demo`)

#### 5.1 功能演示
- **SimpleDemo**：基础功能演示
- **ButtonDemo**：按钮组件展示
- **IntegratedDemo**：集成功能演示

#### 5.2 性能测试
- **SushiPlateTest**：寿司盘动效测试
- **SushiPlateSimpleTest**：性能压力测试
- **ButtonTest**：按钮组件测试

## 技术特性

### 1. 前端技术栈
- **Vue 3**：采用Composition API，提供更好的代码组织和复用
- **Element Plus**：企业级UI组件库，保证界面一致性
- **Vue Router**：单页面应用路由管理
- **Pinia**：状态管理，替代Vuex的现代化方案

### 2. 开发工具
- **Vite**：快速构建工具，提供极速的开发体验
- **SCSS**：CSS预处理器，支持变量和嵌套
- **unplugin-auto-import**：自动导入配置，简化开发流程

### 3. 用户体验优化
- **路由动画**：页面切换动画效果
- **进度条**：页面加载进度提示
- **响应式设计**：适配各种设备屏幕
- **错误处理**：完善的错误页面和提示

### 4. 性能优化
- **懒加载**：路由组件按需加载
- **虚拟滚动**：大数据列表性能优化
- **图片优化**：图片懒加载和压缩

## 系统架构

### 1. 组件架构
```
src/
├── views/          # 页面组件
│   ├── display/    # 传送带大屏
│   ├── menu/       # 菜单浏览
│   ├── admin/      # 管理后台
│   ├── auth/       # 认证页面
│   └── customer/   # 顾客功能
├── components/     # 通用组件
│   ├── cart/       # 购物车组件
│   ├── display/    # 显示组件
│   ├── menu/       # 菜单组件
│   └── common/     # 公共组件
├── stores/         # 状态管理
├── router/         # 路由配置
└── api/           # API接口
```

### 2. 路由结构
- **根路径** (`/`)：重定向到演示页面
- **传送带显示** (`/display`)：核心点餐界面
- **菜单浏览** (`/menu`)：传统菜单浏览
- **管理后台** (`/admin/*`)：后台管理功能
- **用户认证** (`/login`, `/customer-login`)：登录功能
- **演示模块** (`/demo`, `/button-demo`等)：功能演示
