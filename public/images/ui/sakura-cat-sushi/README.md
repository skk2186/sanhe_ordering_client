# Sakura Cat Sushi V3 assets

该目录预留给 themev3「樱花猫咪回转寿司屋」主题资产。母版统一按 3840×1080 规划；本阶段仅有占位文件，没有可运行图片。

- `background/`：完整店内与窗外樱花小镇母背景。
- `stage/`：弧形回转台、轨道与遮挡前后景。
- `cats/`：猫厨师原稿、拆件和循环动作。
- `plates/`：真实商品图片下方的餐盘按钮底图与状态素材。
- `console/`：下侧中央独立点餐台/服务台。
- `effects/`：蒸汽、花瓣、灯笼暖光和火苗等轻量效果。
- `progress/`：三层进度条底图、填充与外框。
- `cart/`：购物车外壳、槽位和状态提示图。
- `transition/`：主题切换时使用的专属视觉素材。

复杂主体应作为图像资产设计；不要用 CSS 从零拼整座寿司店。运行时代码和主题切换注册由后续阶段另行实施。
